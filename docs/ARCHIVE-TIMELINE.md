# 单行三维文章归档

本次把 RhineLabUI 的实体档案、baseline 灯光、磨砂材质和阻尼运动迁移到 `/archive/`。复用已有 GLB，没有重新制作几何，因此博客开发及部署不需要 Blender。

## 结构与维护

- `src/components/archive/ArchiveTimeline.astro`：从 `getSortedPostsList()` 生成文章元数据，按发布时间倒序（忽略置顶），沿用原 URL 生成函数。新增文章后重新构建即可，不需要修改三维模型。
- `archive-timeline.ts`：自定义元素，组合筛选、年份定位、文章摘要、普通文章链接、列表切换，以及 Swup 连接/断开生命周期。
- `timeline-scene.ts`：一维有限时间线；最多 25 个实例槽位，普通档案按五组材质实例化，选中及归位档案暂用完整模型。列数逻辑上等于筛选后的文章数，不循环、不生成补充文章。
- `timeline-motion.ts`：保留速度的临界阻尼、实际释放速度驱动的指数惯性、带负波谷的选中波浪。
- `archive-asset.ts` 与 `rhine/`：来自 RhineLabUI 的材质配置和着色器；Three.js 固定到 0.183.0，避免内部 ShaderChunk 改变时静默破坏磨砂。
- `archive-timeline.css`：归档存在时拓宽主内容并隐藏侧栏；其他路由自动恢复。原站导航、内容系统和路由仍由博客管理。

模型为 `public/assets/archive/archive-cassette.glb`。来源为本机 RhineLabUI 已确认模型；源工程保留在 `E:/RhineLabUI/art/`，模型由其 Blender MCP 制作流程生成。移植代码 MIT 许可保留于 `public/licenses/rhine-lab-ui.txt`。没有迁入原片、配乐或莱茵品牌字体；文章印刷编号和页面品牌使用 Furinafans。

开发：`pnpm dev`。检查：`pnpm check`、`pnpm type-check`、`pnpm build`。

## 交互与边界

拖动、滚轮、左右方向键、前后按钮和位置滑杆均选择文章。Home/End 跳到首尾，滚轮在边界让出页面滚动；手机横向拖动，纵向滚动交由浏览器处理。年份按钮定位该年第一篇。分类、标签和未分类参数使用原 ArchivePanel 的匹配语义。

原归档列表继续服务端输出，保留真实文章链接。无 JavaScript、空筛选、模型加载失败或 WebGL 不可用时保留列表/说明；有场景时可手动切回列表。场景在列表模式、页面隐藏及滚出视口后停止绘制；Swup 卸载释放 renderer、环境目标、后处理、材质、纹理、监听器和观察器。载入期间离开页面，过期资产释放而不接回 DOM。

减少动态效果时不产生波浪、惯性和文字动画，选档直接定位。保留原模型物理透射、阴影和 SSAO，没有根据手机型号自动更换材质。

## 文章选中配色

按用户要求，未选中文件的主体基色改为 `#2964D9`，选中改为 `#022873`。配色集中在 `archive-asset.ts` 的 `FILE_COLOR` / `SELECTED_FILE_COLOR`，作用于端面、背板和嵌片，保留螺丝及印刷标签的辨识度。玻璃保持中蓝染色及中性吸收，避免与深蓝背板两次深蓝叠乘后接近黑色、吞掉内构；盖板暖色乘色也改为中性。选中端面不透射，避免浅色反射背景削弱深蓝状态。磨砂、光照、抬起与归位继续沿用，颜色通过原有材质插值随抬起/归位过渡。色值是材质基色，实际像素仍受光照、透射与色调映射影响。
`pnpm check`、`pnpm type-check` 与最终 `pnpm build` 通过；浏览器复核第 1 篇与连续切换后的第 8 篇，未出现材质或着色器异常。配色截图：`docs/screenshots/archive-selection-blue.png`。

## 与博客背景融合

归档外层取消奶黄色底板与边框，WebGL 使用透明画布及 alpha=0 清屏，移除固定颜色的场景背景和雾。地面改为低透明度 `ShadowMaterial`，仅保留投影。环境贴图仍用于模型照明，SSAO 默认混合与 OutputPass 保留画布 alpha；不通过铺一块近似网站背景色伪装透明。

画布上下边缘使用 CSS 透明度遮罩，替代奶黄色渐变覆盖层，因此网站壁纸或背景装饰可以直接透出。正文、分隔线、元信息和控件改用博客主题色，深色模式单独提供浅色正文。中蓝未选中／深蓝选中材质及现有选档动效保留，不修改 Blender 资产。

本次验收：桌面浅色与深色截图、390px 手机布局；额外用双色背景检查画布空白像素真实透出，并检查列表往返与连续选档后没有重新出现底板。

透明正文不再有卡片底色保护，因此归档页将整页壁纸图片层透明度设为 0.16，避免亮色壁纸干扰深色正文、复杂壁纸干扰手机阅读；规则通过 `body:has(archive-timeline)` 限定，离开归档自动恢复，不改用户保存的壁纸设置。
