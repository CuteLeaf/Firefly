[AstraSchedule](getastra.cn) 里我做了一个很有意思的功能，通过公开的节假日安排数据能够自动推算出当年或往年的调休关系，具体是哪一天工作日补的哪一天休息日，也能反查休息日是从哪个工作日调过来的。

## TLDR 算法流程

**按时间顺序，一一配对。**

 ```mermaid
 flowchart TD
    A[输入年份] --> B[从公开数据获取全年工作日与节假日数据]
    B --> C{遍历节假日，筛选出调休日}
    C --> D[按相同 detail 对调休日进行分组]
    C --> E[按相同 detail 对工作日进行分组]
    D --> F
    E --> F
    
    subgraph F [为每个 detail 建立映射]
        direction LR
        G[对组内调休日排序] --> H
        I[对组内补班日排序] --> H
        H[按顺序配对] --> J[添加到最终映射表]
    end
    
    F --> K[返回映射表]
 ```

算法其实不难，甚至说特别简单。后面主要讲讲这个算法是怎么寻思出来的。

## 怎么想出来的

:spoiler[~~其实也不是很难想~~]，我们平时也会说调休哪一天调的哪一天。尽管更多人更在乎哪天上班哪天下班，但对于学校和学生来说还要关心到底要上哪天的课。这是对于学校来说每年必不可少的脑力劳动。但既然每年都能发出通知来，那说明调休很大可能有一个一一对应的关系。

其实光从 “调休” 这个词来说，他是一个动宾短语，“调” 作为动词有 “调剂” 的意思

> [!TIP] 新华字典 调（tiáo）
> 调剂：以临万货，以～盈虚。

"调休"的本质是重新调配时间资源——当公共假期"盈"（多了休息日）时，就从周末"虚"处（借出休息日）来补，最终实现工作日与休息日的 **总量平衡** 。

到这其实就能直接想出上述的算法了。但是如果你语文跟我一样稀烂，:spoiler[其实上面是我现查的]，那也可以从另一个角度来思考：化学和数学。

初中化学就教了 **化合价** 的概念。初中化学教材告诉我们，原子为了形成一个相对稳定结构，会与其他原子相结合。怎么结合呢？以离子为例，电子发生了 **“转移”** 。类比到调休上，是 **节假日** 发生了 **转移** 。所以我们也可以试着给某一天加上一个 “价态”。

比如我们分析一下 2026 年的元旦假期安排：把本该是工作日的休息日标记成 +1 价，把本该是休息日的工作日标记成 -1 价。原本就是休息日或者工作日没变的标记成 0 价。

| 日期         | 星期    | 状态             | 价态  |
| ---------- | ----- | -------------- | --- |
| 2026-01-01 | 四     | 元旦，本来就休息       | 0   |
| 2026-01-02 | **五** | 休息，**但本该是工作日** | +1  |
| 2026-01-03 | 六     | 周六，本来就休息       | 0   |
| 2026-01-04 | **日** | 工作，**但本该是休息日** | -1  |

Amazing！有趣的是，我们发现这样标记恰好和化合价一样，满足 **代数和为 0** 的性质。也就是说，同一假期分组内，各日期的价态代数和为 0。而且这个算法的结构也比化合价更简单，化合价还有 +2 价 -3 价这样的，但这个算法只有 -1 0 +1 三种价态。

然后到了初中数学发挥的部分：已知

$$
a + b = 0
$$
那么 **a 与 b 互为相反数**

> [!TIP] Wikipedia 相反数（加法逆元）
> 在[实数](https://zh.wikipedia.org/wiki/%E5%AF%A6%E6%95%B8 "实数")中，数 $a$ 的相反数 $−a$ ，称为其加法逆元

显然，$a$ 与 $b$ 任一为 $0$，最终 $a+b$ 都不可能为 $0$。所以 $a$ 与 $b$ 必然一个是 $-1$ 一个是 $+1$。那么，由上文的结论可得，**每个假期分组的日期价态代数和为 0** 可以表述成下面这样：

$$
(a_1 + b_1)+(a_2+b_2)+\cdots+(a_n+b_n)=0
$$

那么对于每一组 $(a_n+b_n)$ 就恰好对应一天休息日和一天工作日。这说明，**调休节假日和调休工作日就是可以一一对应起来的**

最后就是怎么对应的问题，这个就是经验而言，:spoiler[注意到]，一般把**最早的**调休节假日和**最早的**调休工作日对调。也就是说，大部分情况下是按日期顺序来调休的。

那就很简单了：按假日分组，然后**按时间顺序**排好调休工作日和调休节假日，基于上文的结论，直接**一一配对**即可。
