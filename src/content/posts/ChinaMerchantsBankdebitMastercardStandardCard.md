# 招商银行的万事网联卡

> [!NOTE]
> 本文信息仅供参考，均为个人使用体验，可能随政策调整而失效。
> 本文只讨论**借记卡（Debit Card）**。

## 招商银行万事达卡

招行这张万事达卡目前有两个版本：**普卡**与**金葵花卡**。

|       | 普卡       | 金葵花卡             |
| ----- | -------- | ---------------- |
| 卡 BIN | `534293` | `531063`         |
| 办卡门槛  | 无        | 需验资 **50 万 CNY** |
| 结算币种  | 人民币      | 人民币              |

### 普卡（卡 BIN 534293）

#### 核心优势

- **无需换汇**：纯人民币结算
- **双通道**：境内走万事网联（可绑微信、支付宝），境外走 Mastercard
- **支持 3DS**
- 可绑定 Google Play（本人未实际消费，但 B 站有成功案例）
- **预授权冻结 100%**，这一点优于多数卡

#### 卡片权益

| 权益 | 说明 |
| --- | --- |
| 境外汇率补贴返现 | **5‰（0.5%）**，有效期至 2026 年底 |
| 账户管理费 | 免收 |
| 货币兑换手续费 | 免收 |
| 境外 ATM 取现手续费 | 每月**首笔**免收 |
| 境外 ATM 查询手续费 | 免收（查余额） |

> [!IMPORTANT]
> 关于 ATM 相关减免：推测仅免除**招行侧**手续费，**收单行 / ATM 运营方**仍可能单独收费。
> 返现活动是否在 2026 年后延期，官方暂无明确说明。

> 实际使用体验良好，目前未遇到拒付：线上 CVV 支付、微信支付、支付宝均正常（境外线下尚未测试）。

### 金葵花卡（卡BIN 531063）

权益在普卡基础上**有所增加**，未提及的部分与普卡一致。

| 权益 | 说明 |
| --- | --- |
| 境外 ATM 取现 | 每月**前 3 笔**手续费免收 |
| 境外汇款 | 免收汇款手续费，但**少数费用仍需支付** |
| 年费 | **减免**（具体期限请自行向柜面或客服核实） |

## 总结

这张卡的优点比较集中：

1. **纯人民币结算** —— 印象中是国内第一张以人民币结算的 Mastercard
2. **预授权冻结 100%** —— 不必为预授权预留额外余额，且官方明确告知冻结比例
3. **3DS 完善** —— 不用担心网站强制 3DS 时因卡片不支持而被拒付
4. **对未成年人较友好** —— 手机银行可自助锁卡、开启境外支付，无需跑网点。权限虽有限，但总比没有好
5. **支持小额免密** —— 开户时柜面主动询问并直接开通，出卡即可挥卡

> [!TIP]
> 如果有人问我国内哪张万事达借记卡比较好，我会推荐**招商银行万事达普卡**。
