# 关于我 / About Me

你好！我是 **括弧** ，现在高一。
## 🛠️ 关于本站

这个网站使用 **Astro** 框架构建，采用了 [Firefly](https://github.com/CuteLeaf/Firefly) 模板，Firefly 是基于 [Fuwari](https://github.com/saicaca/fuwari) 的二次开发。

平时用 Python 和 Golang，会点前端和运维。

这个博客以随笔为主，基本就是当一个长篇 QQ 空间发，所以可能技术性内容占比不多，也不那么经常更新，~~我天天哪那么多长篇大论的可讲~~。不过博客内容大多也是梦到啥说啥，建议主要当个乐看。~~鄙人更加擅长一本正经的胡说八道。~~

这个站点里发的长文章没有固定的领域，也没有限定的篇幅。不过发到博客上的肯定都是一些长文，你应该也看到这个站点里面的文章大多在 3k 字左右。一些需要富文本的短文也可能发在博客上。

## 🤔 关于动态

动态就是这个站点的 [这个（/dynamic/）](/dynamic/) 页面，数据源来自 [memo.khbit.cn](https://memo.khbit.cn)，所以你也可以直接去 [数据源](https://memo.khbit.cn) 体验更完整的功能。一些短文、备忘等我会发在动态里而不是博客文章。动态倒是可能经常更新的（？

每个动态我会打上 tag 方便检索（博客站点没有 tag 检索功能，检索需前往 [数据源](https://memo.khbit.cn)），目前有这么几个 tags：

| Tag | 何意味                                  |
| --- | ------------------------------------ |
| 观点  | 一些比较短的观点或者思考，一般没有标题或者像博客文章那样非常详尽的论述。 |
| 胡诌  | 瞎扯，梦到啥说啥的。大部分是玩笑话。                   |
| 选题  | 以后可能会写成博客文章的话题，起一个 TODO 作用。          |

已经写了的选题和放弃的选题会归档。
