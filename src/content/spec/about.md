## 🛠️ 关于本站

这个网站使用 **Astro** 框架构建，采用了 [Firefly](https://github.com/CuteLeaf/Firefly) 模板，Firefly 是基于 [Fuwari](https://github.com/saicaca/fuwari) 的二次开发。

平时用 Python 和 Golang，会点前端和运维。

这个博客以随笔为主，基本就是当一个长篇 QQ 空间发，所以可能技术性内容占比不多，也不那么经常更新。~~我天天哪那么多长篇大论的可讲~~，当然比较短的内容我大概也不会发到博客文章里就是。不过随笔内容大多也是梦到啥说啥，可以当个乐看。~~鄙人更加擅长一本正经的胡说八道。~~

文章内容大致在 3k 字左右，也有更长的，比较短的（几百字的）随笔和思考会发在[动态](/dynamic/)。

哦对了，这是我初中三年一直在独立开发的一个项目，是一个能在 Windows 7 上运行，支持集控和远程配置，并且能够自动计算并应用调休安排，适用于班级大屏的电子课表。也许可能帮到你：
